# Typemetric

Typemetric is a lightweight, low-footprint Windows telemetry application designed to track and aggregate keystrokes and mouse clicks in real-time. It provides a visual, interactive heatmap of peripheral usage without compromising privacy.

## Project Documentation (For AI Agents & Developers)

The documentation is heavily sectioned to facilitate modular reading by AI agents. Please refer to the specific files in the `docs/` folder:

- [ARCHITECTURE.md](docs/ARCHITECTURE.md) - System overview, Core modules (GlobalHooks, MetricsTracker), and RAM management.
- [DESIGN.md](docs/DESIGN.md) - Aesthetic choices, Thermal Tech Logarithmic scale, and UI implementation details.
- [DATABASE.md](docs/DATABASE.md) - SQLite schema, data aggregation strategies, and privacy constraints.
